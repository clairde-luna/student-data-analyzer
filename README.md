# Student Data Analyzer

A beginner Python project that loads, cleans, analyzes, and visualizes student academic data.

## Features

- Loads student records from a CSV file
- Cleans missing and invalid data using pandas
- Calculates average, highest, and lowest exam scores
- Identifies students scoring above the class average
- Visualizes exam scores with a bar chart
- Explores the relationship between study hours and exam scores with a scatter plot

## Technologies

- Python
- pandas
- Matplotlib
- CSV data handling

## Project Structure

- `analyzer.py` — Original analysis using core Python
- `pandas_analyzer.py` — Data cleaning, analysis, and visualizations
- `students.csv` — Sample student dataset
- `exam_scores.png` — Exam score visualization
- `study_hours_vs_scores.png` — Study hours versus exam scores
